## 🌸 できること

- 📷 **Google の AI スキャナー**：ピントと輪郭検出が向上、オフライン対応
- 🌍 **15 言語**、国ごとの設定（日付・通貨・用紙・身分証の名称）
- 📄 **PDF ツール**：分割・圧縮・パスワード・透かし・ページ番号
- ✍️ **署名**、書き込み、ハイライト、黒塗り、スタンプ
- 🔤 **文字認識（OCR）**、翻訳、読み上げ、音声入力
- 🧠 **書類に質問**、契約書チェック、フォーム入力
- 🗂️ 期限通知つき **ライフフォルダ**、家計簿、在庫管理
- 🎓 要約と学習カード、PowerPoint と Word
- 📥 PDF・Word・Excel・PowerPoint・EPUB・ZIP・HEIC・TIFF などに対応
- 👋 ようこそ画面、ステップごとのガイド、サウンドと振動

## ⬇️ インストール

1. **[Releases](../../releases/latest)** から **APK** をダウンロード。
2. スマホで開きます。
3. Android に求められたら **「不明なアプリのインストール」** を許可。
4. 完了！**ScanPro** を開いて言語を選びましょう 👋

## 🔒 プライバシー

- 📴 **オフラインで動作**
- 🏠 写真や書類は **スマホの外に出ません**
- 🙅 **アカウント・分析なし**。書き出し時にたまに短い広告
- 📷 カメラは **「写真を撮る」** を押したときだけ起動
