## 🌸 功能

- 📷 **Google AI 扫描**：对焦和边缘检测更好，无需联网
- 🌍 **15 种语言**，并按国家/地区适配（日期、货币、纸张、证件名称）
- 📄 **PDF 工具**：拆分、压缩、密码、水印、页码
- ✍️ **签名**、书写、高亮、涂黑和盖章
- 🔤 **文字识别（OCR）**、翻译、朗读和听写
- 🧠 **向文档提问**、合同审阅和表单填写
- 🗂️ **生活文件夹**：到期提醒、记账和库存
- 🎓 摘要和学习卡片，PowerPoint 和 Word
- 📥 支持 PDF、Word、Excel、PowerPoint、EPUB、ZIP、HEIC、TIFF 等
- 👋 欢迎屏、分步引导、音效和触感反馈

## ⬇️ 安装

1. 前往 **[Releases](../../releases/latest)** 下载 **APK**。
2. 在手机上打开。
3. 如果 Android 提示，请允许 **“安装未知应用”**。
4. 完成！打开 **ScanPro** 选择你的语言 👋
